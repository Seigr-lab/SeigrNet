EXPERIMENT / 4 OCTOBER 2026

Source and conversion history.

All 64 cases completed. Untriggered readings retained the preceding result; small post-return differences depend on reference choice and observation order.

Question and rationale

Does a post-return observation depend on source activation, an intervening conversion, their interaction, or the reference trajectory? The preceding experiment did not establish a consistent delay-only relation across acquisition orders. Its largest contrast was +7 counts although both returned values were 744; the two local references differed. This investigation separates the two actions and retains three references for every case.

The wider objective is sovereignty over all available silicon components and their interconnections: SEIGRASM discovery, direct control and observation, replacement of inherited firmware dependencies, and Hyphos/SeigrOS use of discovered electrical capabilities through native Seigsit relations. This experiment characterizes one source and its acquisition path. Source-enable settings and converter commands are not assigned Seigsit states.

Sixteen blocks execute orders A B D C, B C A D, C D B A and D A C B four times each. Successive four-block cycles traverse that order list forwards, backwards, forwards and backwards. Every case occupies every position four times; each directed predecessor pair inside a block occurs four times. Allocation is deterministic.

Each case establishes the disabled source, waits at least 1,000 microseconds and commands three successive references. A guarded departure write either retains the disabled source or enables it. C and D command an intervening conversion; A and B read CS without a command. All four cases then poll readiness, read RESULT and read CS. The untriggered reading is explicitly retained as an observation of the available result, not counted as a new conversion.

An anchored counter wait holds until 50 microseconds after the departure-write report ends. A guarded return write disables the source, followed by zero added wait and two commanded return observations. Both source writes occur in every case. Channel 4, zero divider, disabled empty FIFO and disabled ADC interrupts remain fixed. No SD transaction occurs among the 120 accesses in a four-case block; recording and admission occur between blocks. Current and sticky errors remain visible without automatic retry.

The 1,000-microsecond preparation interval is not proof of complete settling. The disabled source potential is unspecified. Fifty microseconds sets a scheduled hold, not an exact internal switching interval. All actual access brackets remain recorded.

SEIGRASM changes

The authored access stream adds operation kind 7: wait for an offset from an earlier report's end counter. It records the anchor, offset, computed deadline, counter frequency and entry/exit. Invalid anchors, unusable frequency, overflow and deadlines already reached on entry are refused. The wait performs no device access. Each descriptor is bound to its own preceding departure-write report; recovery independently verifies that relation.

The compact executor now admits up to 128 accesses, allowing all 120 accesses of a block to execute before persistence. It clears report storage and stops at the first failed access. Each block retains a 1,210-cell report. Other executable streams are retained.

Entry instructions lead to SEIGRASM route and control instructions, compact execution, senary journal encoding and SD write/readback. PC Python and PowerShell package authored instruction words and descriptors and recover evidence. No foreign target compiler or target OS is used. Existing entry firmware, processor execution, SD transport and retained bridge configuration remain apparatus dependencies. Acquisition calls no firmware service; full replacement of inherited dependencies remains open.

Verify completeness, source readbacks, commands or their declared absence, errors, deadline anchors and restoration. Retain all cases, including first observations and partial traces. For each completed block, require a common intersection of all four departure-to-return brackets, and separately of all four return-write-to-command brackets, before describing cases as timing-compatible. Overlap cannot prove identical internal physical timing.

Calculate return-minus-reference differences separately from reference 1 and reference 3, for return observations 1 and 2. For those local differences, compare B−A and D−C for source activation; C−A and D−B for the intervening command; and D−C−B+A for interaction. Reference choice, position, drift and all individual readings remain visible. No response sign, magnitude or equality was a pass criterion.

A recurring source or command contrast would support an association under this apparatus. Reference or position dependence would motivate a controlled preparation investigation. Unresolved contrasts would remain unresolved; no preferred result would be selected as a Seigsit state.

Interpretation and next question

The experiment separates a retained RESULT observation from the response after a command, and shows that three nominally identical reference acquisitions are not interchangeable at the one-count scale. Source activation and intervening conversion both associate with small first-return differences relative to the unchanged/no-command case. The second observation reduces the pooled differences, while individual deviations remain. These are bounded associations from one boot, not an identified internal mechanism.

The next discriminating question is whether the reference-position shift follows elapsed time after preparation or conversion activity. A proposed comparison would keep the source disabled, match the total preparation-to-observation interval, and vary the number of intervening conversion commands while retaining a wait-only control. Record the first and later results, deadlines, readiness and source controls without discarding an early reading. This tests the action history behind the shift instead of selecting a delay or omitting data to suppress it. The subsequent preparation time and conversion activity experiment conducts this comparison with fixed source control and matched probe deadlines.

The reusable result for wider silicon discovery is a recorded comparison between an intentional action and the same interval without that action, with local references and explicit result retention. It remains one component-level capability.
